# BankForge

BankForge is a mock banking operations and compliance platform focused on lending, account operations, and automated compliance communications.

## Repository structure

- `common/` shared utilities and configuration
- `servers/` service entrypoints for account, compliance, and lending flows
- `mcp/` Model Context Protocol integration
- `scripts/` data seeding and operational utilities
- `docs/` architecture and rollout documentation
- `evidence/` output artifacts and test evidence
- `docker/` container images
- `data/` product and account data files

## Core capabilities

- Account management
- KYC and compliance reminders
- Loan application processing
- Transaction alert communication
- Demonstration, stress, and showcase scenarios
